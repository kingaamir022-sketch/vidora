  and Dropbox buttons. With a clip: the video frame plays; below it
  a play button and the time display "current | total". Floating
  toolbar above the canvas (appears with a clip selected): "Edit
  with AI" button, then quick-action icons — Crop, Auto reframe
  (Free; converts the video to other aspect ratios), an
  auto-captions icon, a smart-tools icon with a dropdown chevron,
  and "..." ("More options", opens the clip context menu). No
  dedicated safe-zone toggle was found in the preview area. The
  "100%" dropdown and the Hand tool control preview zoom/panning.

## Editor — timeline
- Toolbar (left group, tooltips verified by hovering): Split
  (scissors; disabled at playhead 00:00), Delete (trash;
  Delete/Backspace), Reverse (curved arrow; plays the clip
  backwards), Crop (opens the crop tool for the selected clip),
  Flip horizontal (mirrors the clip), Freeze (pause-bars icon;
  inserts a freeze frame at the playhead; disabled at 00:00),
  Transcript-based editing (lines icon; switches to editing by
  transcript), Split scene (frames icon; "Automatically find scenes
  in a video and split the video into several clips"), Create from
  reference (quotes-like icon; tooltip is exactly that phrase),
  Download clip (download icon with chevron; submenu — download
  the selected clip, or download all content from the selected
  track/sequence).
- Toolbar (center): play button and "current | total" time.
- Toolbar (right group): "Attach" toggle (highlighted blue when
  on; shortcut N; snaps clips together) — tooltip "Turn off
  Attach"; "Preview axis" toggle (shortcut S) — tooltip "Turn on
  preview axis" (shows a comparison guide line on the preview);
  "-" / zoom slider / "+" (timeline zoom); fullscreen icon
  (expands the preview); panel-toggle icon (collapses/expands the
  timeline panel). Time ruler above the tracks with the red
  playhead line. Clips show filmstrip thumbnails and a label
  (name + duration); drag a clip's edges to trim, drag it to move
  it. Track header (left of the track): speaker icon (mute the
  track's audio) and link icon (link/unlink the clip's audio and
  video).
- Right-click menu on a clip: Split (Ctrl B), Copy (Ctrl C), Cut
  (Ctrl X), Paste (Ctrl V, greyed when the clipboard is empty),
  Duplicate (Ctrl D), Delete (Backspace), Replace (Choose File —
  replaces the clip with a file from the device), Download clip
  (submenu), Transcript-based editing, Separate audio (Ctrl Shift
  S — detaches the audio onto its own track), Split scene, Freeze,
  Crop, Flip (submenu), Overlay (submenu), Add overlay (Choose
  File).

## Editor — right inspector (appears when a clip is selected; vertical icon rail: Basic, Background, Smart tools, Audio, Animation, Speed; an X closes it)
- Basic: "Mask" row ("None"; opens mask shapes), "Color
  adjustment" row ("Basic, HSL, Curves"; opens the color panel),
  "Blend" — Mode dropdown ("Normal"), Opacity slider + value box
  (100%), reset icon; "Stabilize" switch (Pro), "Reduce image
  noise" switch (Pro), "Remove flicker" switch (Pro); "Transform"
  — Scale slider + value (100%), Position X/Y value boxes (0/0),
  Rotate (0 degrees), each with a reset icon and a keyframe
  button; "Flip horizontal" and "Freeze" buttons at the bottom.
- Background: three background-mode icons at the top
  (color/blur/image), "Background color" with a color swatch,
  "Recents" swatches, "Brand Color" section, "Recommended"
  palette grid, "Apply to all" button (applies the background to
  every clip).
- Smart tools: rows that each open a sub-panel — Auto reframe
  (Pro; change aspect ratios), Retouch (beauty enhancement),
  Remove background (Pro), Camera tracking (Pro; camera follows a
  selected subject), Relight (enhance lighting), AI movement
  (dynamic camera movements), Optical flow (smoother motion by
  generating intermediate frames).
- Audio — sub-tabs Basic / Voice changer. Basic: Volume slider +
  dB box (0 dB) with reset and keyframe icons, "Fade in and out"
  — Fade-in duration slider (0 s), Fade-out duration slider
  (0 s), "Noise reduction" switch (Pro). Voice changer: a grid of
  voice effects, each with a headphone preview icon (None
  selected; many named presets including Autotune, 3D Surround
  Sound, Valley, Teenager, Sweet, Energetic, Bass Boost, Deep,
  High, Low, Echo, plus seasonal/character voices — names are
  CapCut content, Vidora needs originals), plus "Apply to all".
- Animation — sub-tabs In / Out / Combo (entrance, exit and
  combined animation presets). "Out" shown: None (selected) and a
  large grid of 200+ named exit presets (e.g. Smudge Out, Icy Lens
  Close, Bolt Blackout, Shutter Shut, Slide Down/Up/Right/Left,
  Wave Dissolve, Polaroid Down, Glitch Shutdown — names are CapCut
  content, Vidora needs originals). In and Combo tabs hold the
  matching entrance/combined grids.
- Speed — sub-tabs Normal / Curve. Normal: Speed slider + value
  (1x) with reset icon, Duration box, "Pitch" switch (keeps audio
  pitch when speed changes), "Smooth slow-mo" switch (Pro).
  Curve: speed-ramp presets — None (selected), Custom, Montage,
  Hero, Bullet, Jump Cut, Flash In, Flash Out, plus "Smooth
  slow-mo" (Pro).
