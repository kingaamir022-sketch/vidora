# CapCut Desktop — Screen-Recording Reference (2026-11-25)

**Purpose:** written evidence of exactly what CapCut desktop (version 9.8.0, per the in-app
update tooltip in v10) shows and does, frame by frame, so the Vidora clone can match it.
Source: 10 user-supplied desktop screen recordings, ~13 min total.

**How to read this doc**

- Frames live in `videos-2026-11-25/v01 … v10`. Each folder has `frames/frame_NNN.png`
  (one frame every 5 s; `frame_001` ≈ 0 s, `frame_002` ≈ 5 s, `frame_003` ≈ 10 s, …) and
  `sheet_XX.png` contact sheets (3×3 tiles, in frame order).
- References below are written as `v09/f003` = video 09, `frames/frame_003.png` (≈ 10 s).
- Labels are quoted exactly as they appear. Where a label is cut off by the panel edge in the
  frame it is written with `…` and marked **(truncated in frame)** — never guessed.
- Slider values are given as seen at rest (all `0` unless noted).
- Privacy: no account name/ID, no local file path, no media filename, and no description of
  any person/photo in the preview is recorded anywhere in this doc. Clips are referred to
  only by type and length.
