# N-FONTS — Open-license font library (Phase 5: 40 families)
- **Phase:** 5
- **Reference behaviour:** No font-picker UI was observed in the reference (the Web text inspector has a font dropdown defaulting to "Default"; desktop font UI was never seen). Vidora's font picker is therefore original, marked ASSUMED: a font dropdown in the text inspector listing 40 openly licensed families by category (Sans, Serif, Mono, Display, Handwriting), each with a live preview of its own name in that face; picking one sets the text clip's `fontFamily`. All 40 families are SIL OFL 1.1 except JetBrains Mono (Apache-2.0); the license text ships in `LICENSES/OFL-1.1.txt` and `LICENSES/Apache-2.0.txt`, and every family is listed with its source in `LICENSES/PROVENANCE.md` and `assets/fonts/manifest.json`.
- **Where it lives:** Catalog in `src/lib/fonts.ts` (`FONT_CATALOG`, 40 entries: id, family, category, file, stack, license, source); woff2 files in `public/fonts/` (latin subset, downloaded by `npm run build:assets` from Google Fonts; the script skips files already on disk and skips downloads gracefully when offline); `@font-face` rules in `public/fonts/fonts.css` (generated by `build:assets`, linked from `index.html`); font dropdown in the text inspector (`src/components/PropertiesPanel.tsx` Text section, fed by `FONT_STACKS` + `FONT_CATALOG`).

## Interactions
Select a text clip, open the font dropdown, pick a family — the preview re-renders in that face at once. The choice is stored on the clip's text style (`fontFamily`), undoable and autosaved.

## States
A font file missing from `public/fonts/` (e.g. a fresh text-only checkout): the `@font-face` fails silently and the browser falls back to the family's system stack — the text still renders, never blank. The picker marks such families with "(system fallback)".

## Result
Text renders in the chosen openly licensed face in the preview and in export (export records the preview canvas, so the face is baked in).

## Edge cases
Non-Latin text (Urdu/Arabic/Hindi) in a Latin-subset face falls back to the system font for those glyphs — the app never shows tofu boxes from the font itself; full-script faces arrive with Phase 9 localization.
